# Events & Entertainment

Split payments in two, plus automatic pension micro-contributions (0.01%) from event payments.

<Alert type="info" title="Proprietary Feature">
✨ This is a unique Opendeck feature that automatically contributes 0.01% of event payments to users' pension accounts.
</Alert>

## Overview

When users make payments at events (concerts, sports matches, festivals), Opendeck automatically calculates and contributes 0.01% of the payment amount to their pension account.

**Example:**
- User pays £75 for event tickets
- Automatic micro-contribution: £0.0075 (0.01% of £75)
- Payment processed normally
- Micro-contribution added to pension account

## Split Payments (Pay in Two)

Attendees can split the checkout total evenly between two payers. Each person authorizes their half via open banking; the venue receives the full amount once both payments complete.

**Example:**
- Two friends buy gig tickets for £80 total
- Each pays £40 via open banking
- Order completes when both halves succeed
- Pension micro-contribution (0.01%) is calculated on the full £80

<APIEndpoint method="POST" path="/api/events/payments" description="Process split event payment">
```json
{
  "event_id": "event_12345",
  "payment_type": "ticket",
  "amount": 80.00,
  "currency": "GBP",
  "split_count": 2,
  "split_payers": [
    { "user_id": "user_primary", "amount": 40.00 },
    { "user_id": "user_copayer", "amount": 40.00 }
  ],
  "payment_source": "open_banking"
}
```
</APIEndpoint>

Set `split_count` to `2` to enable pay-in-two. Omit it for a single-payer checkout.

## Step 1: Register as Event Venue

<APIEndpoint method="POST" path="/api/events/venues" description="Register event venue">
```json
{
  "venue_name": "Wembley Stadium",
  "venue_type": "stadium",
  "contact_email": "api@wembley.com",
  "contact_phone": "+44 20 1234 5678",
  "address": "Wembley, London, UK"
}
```
</APIEndpoint>

## Step 2: Process Event Payments

<APIEndpoint method="POST" path="/api/events/payments" description="Process event payment">
**Request:**
```json
{
  "venue_id": "venue_12345",
  "user_id": "user_12345",
  "amount": 75.00,
  "currency": "GBP",
  "event_type": "concert",
  "items": [
    {"name": "Ticket", "amount": 50.00},
    {"name": "Food & Drinks", "amount": 25.00}
  ]
}
```

**Response:**
```json
{
  "payment_id": "pay_abc123",
  "status": "completed",
  "amount": 75.00,
  "micro_contribution": {
    "amount": 0.0075,
    "pension_account_id": "pension_12345",
    "status": "completed"
  }
}
```
</APIEndpoint>

## Step 3: View Micro-Contributions

Users can view their pension micro-contributions from events:

<APIEndpoint method="GET" path="/api/events/contributions" description="Get event contributions">
**Response:**
```json
{
  "contributions": [
    {
      "id": "contrib-uuid",
      "event_payment_id": "payment-uuid",
      "pension_account_id": "pension-uuid",
      "amount": 0.0075,
      "currency": "GBP",
      "status": "completed",

```
</APIEndpoint>
