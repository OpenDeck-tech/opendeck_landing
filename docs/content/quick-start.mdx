Get started with the Opendeck API in minutes. Our RESTful API is designed for simplicity and power.

<Card title="Base URL">
```bash
https://api.opendeck.co.uk
```
</Card>

## Authentication

Opendeck uses JWT-based authentication. Register a user account to get started.

### Getting Your API Token

1. Register a new user account via `POST /api/auth/register`
2. Login to get your access token via `POST /api/auth/login`
3. Include the token in the `Authorization: Bearer YOUR_TOKEN` header

<APIEndpoint method="POST" path="/api/auth/register" description="Register a new user account">
```json
{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john@example.com",
  "password": "securePassword123"
}
```
</APIEndpoint>

<APIEndpoint method="POST" path="/api/auth/login" description="Login and get access token">
```json
{
  "email": "john@example.com",
  "password": "securePassword123"
}
```

Response:
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 3600
}
```
</APIEndpoint>

<Alert type="info" title="Security Note">
Always use HTTPS in production. Never expose your API tokens in client-side code.
</Alert>
